# SHMOT312 NIGHTSHIFT — CRM с Kanban Drag & Drop

Готовый одностраничный сайт для GitHub Pages. Никакой сборки и установки не требуется — весь интерфейс и логика находятся в `index.html`.

## Как обновить GitHub

1. На всякий случай сохраните резервную копию своих данных через **Данные и настройки → Сохранить резервную копию** (если пользовались CRM).
2. Откройте свой репозиторий GitHub.
3. Замените старый `index.html` новым `index.html` из этого ZIP, сохранив имя и расположение файла в корне репозитория.
4. Нажмите **Commit changes**. Если сайт уже опубликован через GitHub Pages, дождитесь обновления и обновите страницу сочетанием Ctrl+F5.

Можно также загрузить всю папку через GitHub, но основной рабочий файл именно `index.html`.

## Новое в этой версии

- **Перетаскивание заказов** мышкой между четырьмя этапами: «Заявка и макет» → «Ждём оплату» → «Производство» → «К выдаче и доставке». Перенос работает в обе стороны.
- **Мобильный и клавиатурный способ** переноса — выпадающий список «Переместить в этап» на каждой карточке.
- **Автосохранение** изменений в том же localStorage, что и в предыдущей версии (`closer_merch_2026_v1`). После перезагрузки доска остаётся в выбранном состоянии.
- **Синхронизация с карточкой заказа**: после переноса можно открыть заказ и увидеть актуальный этап.
- **Цветная подсветка колонки при перетаскивании**, счётчики и выделение переносимого заказа.
- **Без ложных отметок об оплате**: перетаскивание не меняет поле «Оплачено» и не ставит отметку об утверждении макета. Этап «К выдаче» означает «Готов к выдаче», а не «Отправлен».

## Важно

- Канбан показывает **заказы**, а не отдельные заявки-клиенты без созданного заказа. Создать заказ можно через кнопку «Новый заказ».
- Завершённые и отменённые заказы не отображаются на доске, но остаются в разделе «Заказы».
- Факт оплаты, утверждение макета и отправка в реальное производство нужно проверять отдельно. Сайт не подключён к Instagram Direct, WhatsApp и системам цеха.
- Это личный локальный прототип без серверной базы. Данные хранятся **только в том же браузере на том же адресе сайта**, если очистить хранилище браузера, они исчезнут. Для резервного хранения используйте экспорт данных.
