# SHMOT312 NIGHTSHIFT — CRM с вложениями

Обновлённая локальная CRM SHMOT312. **Для сайта нужен только `index.html`.** Никаких серверов, библиотек и ключей API.

## Что добавлено

- **Вложения в карточке клиента:** клиент ещё не оформил заказ, но уже прислал макет/логотип — прикрепите файлы к его заявке.
- **Вложения в карточке заказа:** добавляйте макеты, исходники, видеопримеры, архивы и фотографии.
- **Файлы клиента видны в заказе:** при выборе клиента в форме заказа автоматически появляется отдельный список вложений из его карточки.
- **Любые форматы:** в поле выбора нет фильтра расширений: JPEG/JPG, PNG, GIF, WebP, PDF, PSD, AI, EPS, SVG, CDR, CR2/NEF/ARW/DNG/RAW, AVI/MP4/MOV/MKV, ZIP/RAR/7Z, DOCX и остальные.
- **Несколько файлов и drag-and-drop:** перетащите файлы в область загрузки или выберите через проводник.
- **Действия:** скачать оригинал, удалить из карточки (после сохранения), посмотреть браузерные JPG/PNG/GIF/WebP/AVIF/PDF/MP4/WebM/MP3/WAV/OGG. Другие типы хранятся без изменений, но требуют установленной программы для просмотра.
- **Полная резервная копия ZIP:** раздел «Настройки» → «Скачать ZIP с файлами»; ZIP включает записи и все файлы. Там же можно восстановить их из ZIP.
- Сохранены прежние функции: клиенты, заказы, калькулятор, аналитика, тёмная тема и перетаскивание карточек между колонками производства.

## Использование

1. Откройте **«Заявки и клиенты»** → карточку клиента. Прикрепите файлы в блоке **«Файлы от клиента»** и нажмите **«Сохранить клиента»**.
2. Откройте **«Заказы»** → любой заказ. В блоке **«Макеты и файлы для печати»** добавьте файлы и сохраните заказ.
3. Если файлы были прикреплены к карточке клиента, они будут видны ниже в заказе в блоке **«Файлы из карточки клиента»**.
4. Для переноса данных на другое устройство используйте **«Настройки» → полная копия ZIP**. Обычный JSON **не содержит сами файлы**.

## Как обновить GitHub

1. Распакуйте архив.
2. Откройте репозиторий GitHub.
3. Замените старый `index.html` новым файлом **в корне репозитория**, сделайте **Commit changes**.
4. GitHub Pages при следующем обновлении отобразит новую версию.

## Важные ограничения

- **Загружаемые макеты НЕ отправляются на GitHub, клиентам или в цех.** Вложения сохраняются локально в IndexedDB того браузера, где ими пользовались. Это не общая база компании.
- Файлы доступны только на том же браузере/устройстве и адресе сайта. При открытии сайта с другого адреса, другого браузера или после удаления данных браузера локальные файлы не появятся автоматически.
- Размер ограничен свободной памятью устройства и квотой браузера; расширения файлов при этом не ограничиваются.
- Экспорт ZIP имеет техническое ограничение формата ZIP32 — общий архив не должен превышать примерно 4 ГБ. Для крупных производственных материалов лучше использовать корпоративное облачное хранилище.
- Не добавляйте файлы реальных клиентов в публичный репозиторий GitHub. Делайте регулярную **полную резервную копию ZIP**, храните её в защищённом месте.
- Для синхронизации с командой, предоставления доступа производству или прямого получения файлов из Instagram/WhatsApp потребуются сервер, авторизация, защищённое файловое хранилище и интеграции с сервисами.
- Данные и демонстрационные цены являются примерными, не официальной информацией SHMOT312.
