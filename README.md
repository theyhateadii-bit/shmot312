# SHMOT312 — NIGHTSHIFT CRM

Тёмный дизайн с цветными акцентами для личного сайта-помощника менеджера SHMOT312.

## Как обновить сайт на GitHub

1. Открой свой репозиторий на GitHub.
2. Замени файл **`index.html`** в корне репозитория файлом `index.html` из этого архива (через **Add file → Upload files** или редактирование локальной копии с `git add`, `git commit`, `git push`).
3. Зафиксируй изменения кнопкой **Commit changes**. Если используешь GitHub Pages, дождись публикации — внешний вид обновится автоматически.
4. Если видишь старую версию, обнови страницу с очисткой кэша: **Ctrl+F5**.

Если GitHub Pages ещё не включён: Settings → Pages → Deploy from a branch → main / (root) → Save.

## Что изменено

- Полностью тёмный фон, графитовые панели и объёмные градиенты.
- Лаймовые, фиолетовые, голубые и бирюзовые акценты.
- Цветные статусы, карточки клиентов, заявки и аналитика.
- Новый дизайн окна «Карточка клиента» с тёмными полями, цветными значками и неоновой кнопкой сохранения.
- Адаптация дизайна под мобильный экран и планшеты.
- Сохранены существующие логика CRM, расчёт заказов, экспорт CSV, шаблоны, производственная доска и хранение данных.

## Важно о данных

- Сайт — **локальный прототип без серверной базы и авторизации**. Данные сохраняются в localStorage браузера на конкретном устройстве и адресе сайта.
- При замене `index.html` на том же адресе данные обычно остаются (в этой версии сохранён прежний ключ хранилища). Тем не менее **перед обновлением зайди в «Данные и настройки» и сохрани резервную копию JSON**.
- На новом адресе/другом устройстве база будет отдельной. Её можно перенести через JSON-экспорт и импорт из настроек.
- Не загружай реальные персональные данные клиентов в GitHub-репозиторий. При использовании публичного GitHub Pages без входа в аккаунт не следует хранить там конфиденциальные данные клиентов: для полноценной рабочей CRM нужны авторизация, серверное хранилище и разграничение доступа.
- Instagram и WhatsApp открываются как внешние ссылки, автоматической синхронизации переписок нет.
- Демонстрационные цены вымышлены: замени их в каталоге на реальные перед использованием.

Все стили и скрипты включены в один файл `index.html`. Никакие пакеты и сборка не требуются.
